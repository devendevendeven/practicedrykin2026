\# Проект Alt



\## Описание



Alt — это современная платформа для общения пользователей, предназначенная для организации удобной коммуникации между игровыми сообществами, рабочими коллективами, учебными группами и другими объединениями.



\## Актуальность



В настоящее время существует высокая потребность в удобных средствах цифрового взаимодействия. Проект Alt предлагает концепцию единой платформы для общения и совместной работы пользователей.



\## Цель проекта



Разработка концепции платформы для общения и создание информационного веб-сайта проекта.



\## Задачи проекта



\- анализ существующих решений;

\- проектирование структуры платформы;

\- разработка статического сайта;

\- подготовка документации;

\- оформление отчёта по практике.



\## Используемые технологии



\- HTML;

\- CSS3;

\- Markdown;

\- Git;

\- GitHub.
