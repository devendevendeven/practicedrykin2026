\# Проект Alt



\## Общая информация



Alt — это платформа для общения, разрабатываемая в рамках дисциплины «Проектная деятельность».



\## Актуальность



Современные пользователи ежедневно используют цифровые средства коммуникации. Однако существующие решения не всегда отвечают требованиям различных сообществ. Проект Alt направлен на создание универсальной и удобной платформы для общения.



\## Цель



Разработка концепции современной платформы для общения пользователей.



\## Основные задачи



\- исследование аналогов;

\- проектирование структуры;

\- создание сайта;

\- подготовка документации.



\## Ожидаемый результат



Информационный сайт проекта и комплект проектной документации.
