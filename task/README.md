# Alt — платформа для общения

## Описание проекта

**Alt** — это проект современной платформы для общения, предназначенной для объединения пользователей в удобной и функциональной цифровой среде. Платформа ориентирована на игровые сообщества, учебные группы, рабочие коллективы и любые другие объединения людей, которым необходим удобный инструмент для коммуникации.

Проект выполняется в рамках дисциплины **«Проектная деятельность»** и сопровождается разработкой статического веб-сайта и технической документации.

---

## Цель проекта

Создание концепции современной платформы для общения пользователей различных сообществ и подготовка информационного веб-сайта проекта.

---

## Задачи проекта

- анализ существующих платформ для общения;
- разработка концепции проекта;
- создание структуры веб-сайта;
- подготовка проектной документации;
- изучение Git и GitHub;
- оформление отчёта по практике.
